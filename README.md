# discount_engine_assignment

Язык программирования: JavaScript

Для запуска необходим Node.js (Code Runner для быстрого запуска).

`main.js` — основной код со встроенным order. Для запуска в терминале выполнить:

```bash
node main.js
```

`main for test`, `test.js` — файл с модулями / файл с тестами.

Для запуска тестов `main for test`, `test.js` нужно поместить в одну папку и в терминале выполнить:

```bash
node test.js
```

## Схема классов

* `Product` — товар: id, название, цена, категория.
* `CartItem` — товар и его количество.
* `Customer` — покупатель, дата последней покупки и индикатор первого заказа.
* `Order` — заказ: покупатель, товары, промокод, дата и стоимость доставки.
* `Discount` — базовый класс скидки, от которого другие классы наследуют метод `discountApply()`.
* `discountProcent` — процентная скидка (применяется всегда, когда промокода нет либо он даёт меньшую скидку).
* `discountFix` — фиксированная скидка от 5000.
* `threeIteamsDiscount` — «3 по цене 2».
* `promocodeDiscount` — скидка по промокоду.
* `actualFixPromocode`, `actualProcentPromocode` — есть два вида промокодов: фиксированный и процентный. Расчётный метод выбирается в зависимости от того, какой именно купон ввёл покупатель.
* `firstOrderDiscount` — скидка на первый заказ.
* `deliveryDiscount` — бесплатная доставка от 5000.
* `loyaltyDiscount` — скидка за недавнюю покупку.
* `DiscountFactory` — создаёт нужный объект скидки по конфигурации (имя, значение, применяемое в расчёте скидки).
* `discountEngine()` — последовательно применяет скидки и рассчитывает итоговую стоимость.

## Порядок скидок

Скидки применяются в порядке, указанном в `discountConfig`:

1. 3 по цене 2
2. Промокод / процентная скидка (в зависимости от значения)
3. Скидка на первый заказ
4. Скидка за лояльность
5. Фиксированная скидка
6. Бесплатная доставка

Каждая следующая скидка рассчитывается от текущей суммы после предыдущих скидок. Но бесплатная доставка и фиксированная скидка срабатывают от исходной суммы.

## Правила округления

Для округления используется функция `bankersRound()`.

Округление выполняется до 2 знаков после запятой.

После каждой применённой скидки итоговая сумма округляется заново.
