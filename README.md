# discount_engine_assignment

Язык программирования: **JavaScript**

Для запуска необходим **Node.js**.
Для быстрого запуска можно использовать **Code Runner**.

## Файлы

`main.js` — основной код программы со встроенным заказом.

Для запуска в терминале:

```bash
node main.js
```

`test.js` — файл с тестами.

Для запуска тестов файлы `main.js` и `test.js` должны находиться в одной папке. После этого в терминале выполнить:

```bash
node test.js
```

## Схема классов

* `Product` — товар: id, название, цена, категория.
* `CartItem` — товар и его количество.
* `Customer` — покупатель, дата последней покупки и индикатор первого заказа.
* `Order` — заказ: покупатель, товары, промокод, дата и стоимость доставки.
* `Discount` — базовый класс скидки, от которого остальные классы наследуют метод `discountApply()`.
* `discountProcent` — процентная скидка. Применяется, если промокод отсутствует или даёт меньшую процентную скидку.
* `discountFix` — фиксированная скидка при стоимости заказа от 5000.
* `threeIteamsDiscount` — скидка «3 по цене 2».
* `promocodeDiscount` — скидка по промокоду.
* `actualFixPromocode`, `actualProcentPromocode` — массивы с доступными фиксированными и процентными промокодами. Расчёт выбирается в зависимости от типа введённого промокода.
* `firstOrderDiscount` — скидка на первый заказ.
* `deliveryDiscount` — бесплатная доставка при стоимости заказа от 5000.
* `loyaltyDiscount` — скидка за недавнюю покупку.
* `DiscountFactory` — фабрика, создающая нужный объект скидки по конфигурации (тип, значение скидки и другие параметры).
* `discountEngine()` — последовательно применяет скидки и рассчитывает итоговую стоимость заказа.

## Порядок скидок

Скидки применяются в порядке, указанном в `discountConfig`:

1. «3 по цене 2»
2. Промокод или процентная скидка — в зависимости от промокода и его значения.
3. Скидка на первый заказ.
4. Скидка за лояльность.
5. Фиксированная скидка.
6. Бесплатная доставка.

Каждая следующая скидка рассчитывается от текущей суммы после предыдущих скидок.

Фиксированная скидка и бесплатная доставка проверяют исходную стоимость заказа.

## Правила округления

Для округления используется функция `bankersRound()`.

Округление выполняется до 2 знаков после запятой по правилу **Half to Even**.

После каждой применённой скидки итоговая сумма округляется заново.
